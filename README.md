# LVCC Meal Stub Management System

## Project Description
The **LVCC Meal Stub Management System** is a web-based application developed for the La Verdad Christian College (LVCC) Meal Assistance Program. It streamlines the workflow between Class Secretaries—who submit daily class attendance and request meal stubs—and PSAS (Student Affairs/Services) staff, who verify attendance, monitor distribution, and issue meal stub batches. The system ensures accurate tracking, role-based access control, and complete transparency across all course sections.

## Basic Instructions for Running the Project
When you land on the login page, log in based on your assigned position:
   * **Class Secretary:** Log in using your secretary credentials to access the Section Overview, submit daily attendance reports, and monitor the student distribution tracker.
   * **PSAS Staff:** Log in using your PSAS credentials to review and verify class attendance, issue meal stub batches, monitor inventory, and check reports.
